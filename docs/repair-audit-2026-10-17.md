## Performance evidence and limits

The requested Chrome Performance recording and browser viewport inspection could not be completed: the computer-use safety layer stopped browser interaction because it could not confidently verify the current URL. The user authorized proceeding with the suitable alternative. No FPS, CPU-throttled frame-time improvement or completed visual viewport audit is claimed.

The deterministic atmosphere test exercises 120 frames, a live theme switch, resizing and hidden-document behavior. Previously the source created a background gradient and vignette every frame (240 static-gradient constructions over 120 frames). The repaired implementation creates those two static gradients once until theme/size/context changes (2 over the same steady-state interval). Animated nebula gradients remain. Hidden rendering performs no additional fills. Pointer DOM updates are capped at one per animation frame and particles retain their existing rate/cap. These are operation counts, not end-to-end browser timings.

The layout has explicit rules for mobile and intermediate widths and viewport-height bounds. The semantic text colors pass 4.5:1 checks against the three primary surfaces in both themes. Full rendered-screen contrast, all 360px/768px/600px-high combinations and subjective appearance still need a browser inspection once access works.
