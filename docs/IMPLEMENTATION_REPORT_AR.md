# تقرير تنفيذ واختبار Forgotten Network

التاريخ: 6 أكتوبر 2026. المستودع الفعلي: https://github.com/ABDILAZIZT/ForgottenNetwork — الفرع `main`.

نُفذت التغييرات في نسخة Git مستقلة داخل `verified-main`، مع الحفاظ على المجلد الأصلي. لم أجرِ عمليات كتابة اختبارية على الموقع الحي، ولم أمسح أو أنشر مسودات المختبر الثماني، ولم أشغّل أوامر ترحيل مباشرة على قاعدة الإنتاج. الرفع إلى GitHub يمكن أن يشغّل نشر Render وترحيلات بدء التشغيل.

## النتائج المنفذة

| البند                | التغيير والنتيجة                                                                                                                                                                                                                                        |

## الملفات والترحيلات المهمة

- `client/src/permanent/draftPreference.ts`، `PermanentWorld.tsx`، `CanvasEngine.ts`: حالة المسودات وإدارة الأعمال والمزامنة.
- `client/src/economy.ts`، `client/src/download.ts`: منح العملات وتنزيل الملفات.
- `server/permanent/store.js`، `api.js`: الملكية والحذف والاستعادة والإشغال؛ جداول SQLite إضافية تحفظ التاريخ والطلبات ومراجعة حالة الحذف.
- `server/migrations/004_classic_ownership.sql` و`005_classic_history_guard.sql`، و`server/migrate.js`: ملكية Classic والترقية الآمنة لقاعدة تحتوي بيانات سابقة. لم تُعد كتابة بصمة الترحيل 004 المنشورة.
- `server/contentSafety.js`، `server/permanent/safety.js`: حماية النصوص والبلاغات وطلبات الخصوصية.
- `client/src/Policies.tsx`، `policies.css`، `client/public/THIRD_PARTY_NOTICES.txt`: الصفحات والتراخيص.
- `docs/TRUST_AND_SAFETY.md`: تدقيق البنود العشرين، والمزودات والتخزين والحدود وخطوات التشغيل المطلوبة.

## الحدود والاعتمادات غير المكتملة

1. **لا يوجد فحص بصري تلقائي بالذكاء الاصطناعي.** لا مزود أو بيانات اعتماد مهيأة. فحص الصور الحالي تقني للصيغة والحجم؛ الرسوم المركبة ومعاينات الرسم قد تتضمن محتوى لا يكتشفه مرشح الكلمات. لا ضمان لبيئة آمنة تمامًا للأطفال. يلزم مزود وتقييم فني وإفصاح خصوصية وخطة فشل ومراجعة بشرية.
2. **المشرفون يحتاجون إعدادًا وتشغيلًا فعليًا:** `CANVAS_MODERATOR_IDS` يحتوي UUIDs موثوقة. بلاغات الملفات الشخصية تحتاج معالجة المشغّل؛ الواجهة لا تخفي الاسم/الملف الشخصي حاليًا. لا موعد استجابة مضمون.
3. **حذف البيانات طلب وليس محوًا تلقائيًا:** توجد قائمة ومرجع وحالة، لكن لا معالج محو مكتمل أو مدة احتفاظ/تنظيف تلقائي. يلزم تحديد الاحتفاظ وتوثيق إجراء معالجة قبل اعتبار الطلب منجزًا.
4. **بيانات المشغّل والقانون:** الاسم التجاري/التواصل/الاختصاص ومدد الاحتفاظ غير متحققة. لا نظام موافقة ولي أمر موثقة، ولا ادعاء امتثال قانوني. لم أضف تاريخ ميلاد أو مربعًا يوهم بتحقيق هذه المتطلبات.
5. **التخزين على Render:** ملف `render.yaml` لا يعلن قرص SQLite دائمًا. يجب التحقق من الإعداد الفعلي لـ`PERMANENT_DB_PATH` والقرص والنسخ الاحتياطي قبل الاعتماد على بقاء البيانات عبر النشر. فحص الصحة لا يثبت ديمومة التخزين.
6. **التصدير:** يلزم تأكيد تنزيل فعلي في متصفح يدعم التنزيلات؛ الاختبار داخل المتصفح المدمج لم يكتمل بنجاح.
7. **الوصول الكامل:** التحسينات لا تمثل شهادة WCAG؛ يلزم اختبار قارئ شاشة وهواتف فعلية. الرسم الحر لا يزال يحتاج مؤشرًا.
8. **ملكية Classic القديمة:** السجل الغامض يبقى مقفلًا بدل نسبته تخمينًا لشخص. الممحاة المنشورة تحذف العمل المستهدف كاملًا وليست محوًا جزئيًا لبكسلاته.
9. **النصوص:** قائمة الكلمات محدودة وقابلة للفوات والإنذارات الخاطئة؛ ليست فهمًا شاملًا لكل اللغات. لا توجد مراقبة آلية شاملة لكل محتوى مرسوم.

لم تُضف نافذة موافقة تتبع اختيارية لأن المراجعة لم تجد SDK إعلانات/تحليلات اختيارية مفعلة عمدًا في هذه النسخة. التخزين الضروري موضح في سياسة التخزين، وأي تتبع خارجي غير موجود في المستودع يحتاج تدقيق المشغّل.
