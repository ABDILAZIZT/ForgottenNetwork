تم تأكيد نجاح أوامر push لهذه الدفعات إلى `origin/main` في المستودع `ABDILAZIZT/ForgottenNetwork`. لم يُستخدم force-push. لم تُنفّذ عمليات كتابة تجريبية على قاعدة الإنتاج، ولم تُنشر مسودات الاختبار القديمة.

## الوظائف الجديدة والمصلحة

- حجم القلم والإعدادات يؤثران في الرسم. أزيلت الإطارات المتكررة المحيطة بالمسودات، وبقيت مؤشرات التحديد والتعارض اللازمة.
- ألوان HEX/RGB/HSV ولوحات الألوان متاحة، مع إبقاء الأدوات الأساسية مجانية. أضيفت قطّارة مع عدسة معاينة، وشبكة ومساطر ومحاذاة إلى الشبكة.
- محرر Studio يوفّر تعبئة متصلة مع tolerance، تحديدًا مستطيلًا وحرًا، نقلًا وتكبيرًا وتدويرًا، وفلاتر اللون، وما يصل إلى 8 طبقات مع الترتيب والإظهار والقفل والشفافية.
- يمكن ضبط موضع العمل في العالم وحجمه. تُحفظ نتيجة العمل الجديد كمسودة حتى إن كان وضع النشر المباشر مفعّلًا.
- تعديل عمل منشور يتطلب هوية مالكه وإصداره الصحيح. تعارض الموضع الجديد يتراجع عن العملية كاملة. النسخة السابقة تبقى في سجل الاسترجاع. اختبارات HTTP تؤكد رفض هوية ثانية عند التعديل والحذف.
- رفع الصور يفتح معاينة قابلة للتحرير، وGIF يحتفظ بالحركة مع ضبط الحجم والتدوير. صور الحساب الجديدة تُقص دون تشويه وتُحفظ بدقة 256px؛ الصور القديمة لا تُستبدل تلقائيًا.
- زر Publish أصبح في الشريط العلوي. تحسّن تباين الثيم الفاتح، وتوزيع الأزرار في الهاتف، وإتاحة أدوات العوالم المحفوظة من الواجهة الرئيسية.
- أزيل مدخل Classic المنفصل ومكوّناته القديمة. احتُفظ بمخازن البيانات وواجهات API وتسجيل الدخول والمراجعة والمكافآت والإعلانات التجريبية والتصدير والاستيراد. تظهر الكتابات المعلقة مع خيار إعادة المحاولة أو الإلغاء الصريح.

## التحقق الفعلي

| الفحص              | النتيجة                                                                       |
| ------------------ | ----------------------------------------------------------------------------- |
| `pnpm lint`        | ناجح في آخر تشغيل                                                             |
| `pnpm test`        | 3 اختبارات مشتركة + 51 للواجهة + 50 للخادم؛ كلها ناجحة                        |
| `pnpm build`       | TypeScript وVite ناجحان في آخر تشغيل                                          |
| `git diff --check` | ناجح قبل commit الواجهة                                                       |
| التنسيق            | تنسيق الملفات المعدّلة؛ لم يُدّعَ إصلاح مشاكل التنسيق القديمة في المستودع كله |

كشف التحقق خطأ JSX أثناء إضافة تدوير الصور، وأُصلح ثم أُعيد تشغيل lint والبناء بنجاح قبل الرفع.

اختبار المتصفح استخدم خادمًا محليًا منفصلًا ولوحة في الذاكرة: إنشاء فنان تجريبي، الرسم والتحديد ومعاينة النقل والتدوير، حفظ مسودة، إعادة تحميل مع بقاء وضع المسودات وعددها، الثيم الفاتح، عرض بعرض 390px، ربط هوية الفنان بأدوات العوالم المحفوظة، إنشاء كائن تجريبي في الأرشيف، وتنزيل ملف JSON فعليًا. لم تظهر أخطاء في سجل المتصفح الذي فُحص. هذه اختبارات استكشافية وليست ضمانًا بخلو جميع المسارات من الأخطاء.

## حدود باقية يجب معرفتها

1. دمج **عرض العالم القديم بالكامل** داخل العالم الحديث غير مكتمل. البيانات القديمة متاحة من لوحة الأدوات، لكنها لا تُرسَم تلقائيًا فوق اللوحة المشتركة؛ لذلك لا يصح ادعاء تطابق وظيفي كامل مع عارض Classic السابق.
2. أدوات التحديد والتعبئة والتحويل تعمل داخل محرر العمل المختار، لا على منطقة عشوائية تضم أعمال الآخرين. النسخة الناتجة PNG مسطّحة؛ تحرير GIF منشور داخل المحرر ينتج إطارًا ثابتًا مع إبقاء الأصل في التاريخ.
3. لا توجد صيغة مشروع تحفظ الطبقات للتحرير لاحقًا، ولا حفظ تلقائي لجلسة المحرر. احفظ مسودة أو نزّل الملف قبل الإغلاق. التراجع يشمل عمليات الرسم والمعالجة، ولا يشمل تغيير بنية الطبقات.
4. تحرير بلاطة قديمة يدمج طبقاتها. البيانات المحلية ليس لها سجل استرجاع خادمي؛ يجب تصدير نسخة قبل استبدال الأرشيف أو حذف بياناته. البلاطات ذات الملكية القديمة الملتبسة تبقى مقفلة وفق قواعد الخادم.
5. لا يوجد فحص صور تلقائي بالذكاء الاصطناعي. تبقى حدود فلترة النصوص وطلبات الحذف والمراجعة وبيانات المشغّل والمتطلبات القانونية كما هو موضح في `TRUST_AND_SAFETY.md`. لم تُضف خدمة خارجية ولم يُدّعَ ضمان سلامة جميع الصور.
6. تسجيل OIDC يحتاج إعدادات المشغّل ولم يُختبر مع مزوّد إنتاج. إعداد Render الموجود في المستودع لا يثبت وجود قرص SQLite دائم؛ إعداد التخزين الفعلي والنسخ الاحتياطي يحتاج التحقق من حساب الاستضافة.
7. العملات والمكافآت تجريبية ومحلية، بلا قيمة نقدية. الأدوات الأساسية متاحة دون ترقية. قيود المنح المحلية لا تحوّلها إلى نظام مالي موثوق ضد تعديل تخزين المتصفح.

تفاصيل الملفات والعقود ومطابقة الأدوات القديمة والجديدة في [STUDIO_MIGRATION.md](STUDIO_MIGRATION.md) و[PERMANENT_CANVAS.md](PERMANENT_CANVAS.md). حالة النشر الحي تُبلَّغ منفصلة عن نجاح GitHub؛ لا يكفي نجاح push لإثبات اكتمال نشر Render.
